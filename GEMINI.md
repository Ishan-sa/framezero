# GEMINI.md

All instructions for AI assistants working in this repository live in one
file: [`AGENTS.md`](AGENTS.md).

Read it before running anything. It covers preflight and dependency install,
what to ask the user, the run, which outputs to read in which order, the
mandatory draft-check loop, troubleshooting, and the ground rules that must not
be broken (most importantly: never commit `data/`, `out/`, or `projects/*.json`,
and never average two creators' voices).
